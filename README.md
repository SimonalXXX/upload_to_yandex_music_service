# ♫ Музыкальный

Скачивает лайки из SoundCloud и загружает их в плейлист Яндекс Музыки.  
MP3 320 kbps, с обложками и тегами, без дублей, с прогрессом в реальном времени.  
Работает на **macOS**.

---

## Быстрый старт

1. Распакуй архив
2. Дважды кликни **`Установка.command`**

Всё. Скрипт сам поставит Homebrew, Python 3.14, ffmpeg, создаст окружение `.venv` со всеми пакетами и запустит приложение.

> Если macOS не даёт запустить: правый клик → «Открыть» → «Открыть» в диалоге.  
> Может попросить пароль от компьютера — это нормально, нужно для установки.

В следующий раз для запуска — двойной клик по **`Запуск.command`**.

---

## Как пользоваться

После запуска откроется браузер с интерфейсом (`http://127.0.0.1:5555`).
Чтобы открывать его отдельным окном, как приложение: в Chrome — меню ⋮ → «Трансляция, сохранение и отправка» → «Установить страницу как приложение»; в Safari — «Файл» → «Добавить в Dock».

### 1. Первый запуск

Приложение проведёт по шагам:

1. **SoundCloud** — введи имя из адреса профиля `soundcloud.com/ТВОЁ_ИМЯ` (или вставь ссылку). Приложение сразу покажет имя профиля и число лайков.
2. **Яндекс Музыка** — войди в [music.yandex.ru](https://music.yandex.ru) в **Google Chrome**, вставь ссылку на свой плейлист. Шаг можно пропустить и только скачивать.
3. **Проверить лайки** — появится список треков.

### 2. Медиатека

Слева — разделы: *Все треки, Новые, На диске, В Яндекс Музыке, Не в ЯМ*, а также *Пропали из лайков, Недоступные, С ошибкой*, когда в них что-то есть. Сверху — поиск и сортировка.

Отметь треки галочками (или «Выбрать» → «Все новые»). Внизу появится панель действий:

| Кнопка | Что делает |
|---|---|
| **Скачать** | Скачивает в папку `Music/` (MP3 320 kbps с обложкой и тегами) |
| **Скачать и в ЯМ** | Скачивает и загружает в плейлист Яндекс Музыки |
| **Загрузить в ЯМ** | Загружает уже скачанные |
| **Уже в ЯМ** / **Снять «В ЯМ»** | Отметить вручную / вернуть трек в очередь на загрузку |

У каждого трека (кнопка ⋯ или правый клик): послушать, открыть на SoundCloud, показать в Finder.

### 3. Синхронизировать одной кнопкой

**«Синхронизировать»** сверху справа: проверит лайки → скачает новые → загрузит в ЯМ → сверит плейлист. Ход задачи — в индикаторе рядом (клик — журнал), остановить — ■ или **⌘.**. Остальным приложением можно пользоваться, пока задача идёт.

### 4. Автосинхронизация

«Настройки» → «Автосинхронизация»: раз в 1–24 часа приложение само синхронизирует лайки и пришлёт уведомление macOS, если появились новые треки или ошибки. Работает, пока открыт `Запуск.command`.

### 5. Сверка и история

- **Сверка** — что из отмеченного «В ЯМ» реально лежит в плейлисте: ненайденные можно выбрать и загрузить заново или снять с них отметку; дубли и треки в обработке — списком.
- **История** — последние 50 операций с итогами и журналом.

### Горячие клавиши

| Клавиши | Действие |
|---|---|
| ⌘F | Поиск |
| ↑ ↓ (Shift — выделение) | Перемещение по списку |
| X или Enter | Отметить трек |
| ⌘A | Выбрать все в разделе |
| Пробел | Играть / пауза |
| ⌘. | Остановить задачу |
| Esc | Снять выбор |

## Вопросы и проблемы

### «Python не найден» / «Окружение не установлено»
Запусти **`Установка.command`** — он поставит `python@3.14` через Homebrew и пересоздаст `.venv`.
Системный Python macOS (3.9) не используется: свежий yt-dlp требует 3.10+.

### «ffmpeg не найден»
`brew install ffmpeg`

### «Не авторизован в ЯМ»
Войди в [music.yandex.ru](https://music.yandex.ru) в Google Chrome и обнови проверку.
Если пишет «macOS не даёт доступ к данным Chrome» — Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску → включи «Терминал».
Подробная проверка — двойной клик по **`Диагностика.command`**.

### Трек «Недоступен»
Часть треков SoundCloud скачать нельзя: защищены DRM (контент SoundCloud Go+), удалены автором или недоступны в стране. Причина — в подсказке к статусу. Такие треки собираются в разделе «Недоступные» и больше не считаются новыми.

### macOS не даёт запустить .command файл
Правый клик по файлу → «Открыть» → в диалоге нажми «Открыть».  
Или: Системные настройки → Конфиденциальность и безопасность → разрешить.

## CLI-режим

Для продвинутых — запуск без веб-интерфейса:

```bash
.venv/bin/python sc_downloader.py                          # скачать лайки с SoundCloud
.venv/bin/python sc_downloader.py --upload                 # загрузить папку в ЯМ (URL из config.yaml)
.venv/bin/python ym_uploader.py <URL_плейлиста> [-d Music] # загрузить папку в плейлист ЯМ
```

## Структура проекта

```
├── Установка.command     # Установка (двойной клик)
├── Запуск.command        # Запуск (двойной клик)
├── Диагностика.command   # Проверка доступа к Яндекс Музыке (двойной клик)
├── .venv/                # Python-окружение (создаётся при установке)
├── web_app.py            # Локальный сервер (API + события)
├── templates/, static/   # Интерфейс (HTML, CSS, JS-модули)
├── sc_downloader.py      # Загрузчик SoundCloud
├── ym_uploader.py        # Загрузчик Яндекс Музыки
├── config.yaml.example   # Шаблон настроек
├── config.yaml           # Твои настройки (создаётся при установке)
├── requirements.txt      # Python-зависимости
├── tracks.csv            # База треков и их статусов (создаётся автоматически)
├── archive.txt           # Уже скачанные треки (создаётся автоматически)
├── upload_archive.txt    # Уже загруженные в ЯМ (создаётся автоматически)
├── history.json          # История операций (создаётся автоматически)
└── Music/                # Скачанная музыка
```
