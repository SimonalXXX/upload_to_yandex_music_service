# ♫ Музыкальный

Скачивает лайки из SoundCloud и загружает их в плейлист Яндекс Музыки.  
MP3 320 kbps, с обложками и тегами, без дублей, с прогрессом в реальном времени.

---

## Быстрый старт

### macOS

1. Распакуй архив
2. Дважды кликни **`Установка.command`**

Всё. Скрипт сам поставит Homebrew, Python, ffmpeg, все пакеты и запустит приложение.

> Если macOS не даёт запустить: правый клик → «Открыть» → «Открыть» в диалоге.  
> Может попросить пароль от компьютера — это нормально, нужно для установки.

В следующий раз для запуска — двойной клик по **`Запуск.command`**.

### Windows

1. Распакуй архив
2. Дважды кликни **`Установка.bat`**

Всё. Скрипт сам скачает и поставит Python, ffmpeg, все пакеты и запустит приложение.

> Если Windows выдаёт предупреждение — нажми «Подробнее» → «Выполнить в любом случае».

В следующий раз для запуска — двойной клик по **`Запуск.bat`**.

### Linux

```bash
sudo apt install python3 python3-pip ffmpeg
cd Музыкальный
pip3 install -r requirements.txt
cp config.yaml.example config.yaml
python3 web_app.py
```

## Как пользоваться

После запуска откроется браузер с интерфейсом (`http://127.0.0.1:5555`).

### 1. Подключи SoundCloud

Введи своё имя пользователя SoundCloud в поле сверху.  
Найти его можно в URL своего профиля: `soundcloud.com/ТВОЁ_ИМЯ`.

### 2. Проверь новые треки

Нажми **«Проверить новые»**. Программа просканирует твои лайки и покажет сколько новых треков появилось с прошлого раза. Рядом с числом треков появится зелёный **+N**.

### 3. Скачай

Два варианта:

| Кнопка | Что делает |
|---|---|
| **Скачать** | Скачивает новые треки на компьютер в папку `Music/` |
| **Скачать + ЯМ** | Скачивает + загружает в плейлист Яндекс Музыки |

Во время скачивания отображается прогресс-бар и название текущего трека.  
Можно остановить в любой момент кнопкой **«Остановить»** — уже скачанное сохранится.

### 4. Яндекс Музыка (опционально)

Чтобы автоматически загружать треки в Яндекс Музыку:

1. Войди в [music.yandex.ru](https://music.yandex.ru) в **Google Chrome**
2. Создай или открой плейлист, скопируй его URL из адресной строки
3. Вставь URL в поле «URL плейлиста» в приложении
4. Нажми **«Проверить авторизацию»** — должно показать зелёную галочку с логином

Кнопка **«Только загрузить в ЯМ»** отправит в Яндекс всю уже скачанную музыку.

## Вопросы и проблемы

### «Python не найден»
- **Windows**: скачай с [python.org](https://www.python.org/downloads/), при установке поставь галочку **«Add Python to PATH»**
- **macOS**: установщик поставит автоматически через Homebrew

### «ffmpeg не найден»
- **macOS**: `brew install ffmpeg`
- **Windows**: `winget install ffmpeg` или скачай с [ffmpeg.org](https://ffmpeg.org/download.html)
- **Linux**: `sudo apt install ffmpeg`

### «Не авторизован в ЯМ»
Войди в [music.yandex.ru](https://music.yandex.ru) в Google Chrome и обнови проверку.

### macOS не даёт запустить .command файл
Правый клик по файлу → «Открыть» → в диалоге нажми «Открыть».  
Или: Системные настройки → Конфиденциальность и безопасность → разрешить.

### Windows блокирует .bat файл
Нажми «Подробнее» → «Выполнить в любом случае».

## CLI-режим

Для продвинутых — запуск без веб-интерфейса:

```bash
python3 sc_downloader.py                          # скачать лайки с SoundCloud
python3 sc_downloader.py --upload                 # + загрузить в ЯМ (URL из config.yaml)
python3 ym_uploader.py <URL_плейлиста> [-d Music] # загрузить папку в плейлист ЯМ
```

## Структура проекта

```
├── Установка.command     # Установка для macOS (двойной клик)
├── Установка.bat         # Установка для Windows (двойной клик)
├── Запуск.command        # Запуск для macOS (двойной клик)
├── Запуск.bat            # Запуск для Windows (двойной клик)
├── web_app.py            # Веб-интерфейс
├── sc_downloader.py      # Загрузчик SoundCloud
├── ym_uploader.py        # Загрузчик Яндекс Музыки
├── config.yaml.example   # Шаблон настроек
├── config.yaml           # Твои настройки (создаётся при установке)
├── requirements.txt      # Python-зависимости
├── archive.txt           # Уже скачанные треки (создаётся автоматически)
├── upload_archive.txt    # Уже загруженные в ЯМ (создаётся автоматически)
└── Music/                # Скачанная музыка
```
