# Контракт CLI

Запуск — интерпретатором из окружения проекта: `.venv/bin/python <скрипт>` (Python 3.14,
создаётся `Установка.command`). Системный `/usr/bin/python3` (3.9) не подходит: yt-dlp требует 3.10+.
Относительные пути из `config.yaml` (`output.directory`) считаются от папки проекта, а не от текущего каталога.

## `sc_downloader.py`

**Назначение:** скачивание лайков SoundCloud через `yt-dlp`, опционально планировщик и загрузка в ЯМ.

### Аргументы

| Аргумент | Описание |
|----------|----------|
| `--url URL` | Источник вместо `soundcloud.profile_url` в конфиге |
| `--config PATH` | Путь к `config.yaml` |
| `--schedule` | Режим планировщика |
| `--force` | Игнорировать `archive.txt` |
| `--stats` | Вывести статистику и выйти |
| `--upload` | Загрузить музыку в ЯМ по конфигу и выйти |

### Взаимодействие с конфигом

- Если в `schedule.enabled` установлено `true`, запуск **без** `--schedule` всё равно переводит процесс в режим планировщика (как `--schedule`).
- После обычного скачивания при `yandex_music.auto_upload` и непустом `playlist_url` вызывается загрузка в ЯМ.

### Коды выхода

Поведение по умолчанию Python: `0` при успехе, ненулевой при необработанном исключении. Явных `sys.exit` с кодами в скрипте при отсутствии конфига — завершение с кодом `1`.

## `ym_uploader.py`

**Назначение:** загрузка аудиофайлов в плейлист Яндекс Музыки по HTTP.

### Аргументы (позиционные и флаги)

| Параметр | Описание |
|----------|----------|
| `playlist_url` | Первый позиционный аргумент — URL плейлиста |
| `--dir`, `-d` | Каталог с музыкой (по умолчанию `./Music`) |
| `--files`, `-f` | Явный список файлов |
| `--delay` | Пауза между загрузками (сек) |

### Учёт загрузок

Успешно загруженные файлы дописываются в `upload_archive.txt` рядом со скриптом (или переданный `archive_path` в API функции `upload_to_yandex`): путь относительно папки проекта (старые записи — абсолютные).
Уже загруженные определяются **по имени файла**, а не по полному пути — перенос папки проекта не приводит к повторной загрузке.

### Плейлист

Загружать можно только в **свой** плейлист: ссылка на чужой (`/users/<другой логин>/playlists/…` или UUID чужого плейлиста) отклоняется с ошибкой, а не отправляет треки в ваш плейлист с тем же номером.

### Зависимости окружения

- Только macOS.
- Авторизация в Яндекс Музыке в **Google Chrome** на той же машине (cookies через `pycookiecheat`; при первом чтении macOS спросит доступ к Связке ключей, процессу нужен «Полный доступ к диску» для папки Chrome).

## Согласованность с веб-приложением

После успешной загрузки через `web_app.py` путь также записывается в тот же `upload_archive.txt`, чтобы CLI не дублировал загрузку тех же файлов.
